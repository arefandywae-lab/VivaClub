# 📱 วิธีลงแอปใน iPhone (อยู่ได้ 7 วัน ไม่ต้องต่อคอม)

พี่สามารถลงแอปใน iPhone ตัวเองได้ฟรี โดยใช้ **Free Apple Developer Account** ครับ
เมื่อลงเสร็จ **สามารถถอดสาย** และใช้งานได้ประมาณ **7 วัน** ครับ (หลังจากนั้นต้องเสียบสายลงใหม่)

### 1. เปิดโปรเจคใน Xcode
1. เปิด Terminal พิมพ์คำสั่ง:
   ```bash
   open ios/Runner.xcworkspace
   ```
2. Xcode จะเปิดขึ้นมา

### 2. ตั้งค่า Apple ID
1. ใน Xcode กดที่โปรเจค **Runner** (ซ้ายบนสุด)
2. เลือก **Signing & Capabilities**
3. ตรง **Team**:
   - ถ้ามีชื่อพี่อยู่แล้ว ให้เลือกชื่อพี่ (Personal Team)
   - ถ้ายังไม่มี ให้กด **Add an Account...** -> ลอคอินด้วย Apple ID ของพี่
4. **Bundle Identifier**:
   - เปลี่ยน `com.vivaclub.vivaClub` เป็นอะไรก็ได้ที่ไม่ซ้ำ เช่น `com.vivaclub.test.[ชื่อพี่]`
   - เพื่อให้ Apple ยอมให้เรา Sign

### 3. ลงแอปในเครื่อง
1. **เสียบสาย iPhone** เข้ากับ Mac
2. ใน Xcode ตรงแถบด้านบน (ข้างปุ่ม Play ▶️) ให้เลือก Device เป็น **iPhone ของพี่**
3. กดปุ่ม **Play (Run)** ▶️
4. รอจน Xcode ขึ้น **Build Succeeded** และติดตั้งแอป

### 4. ยืนยันความปลอดภัย (ทำครั้งแรก)
เมื่อแอปติดตั้งเสร็จ มันอาจจะยังเปิดไม่ได้ ให้ทำดังนี้ที่ iPhone:
1. ไปที่ **Settings** (การตั้งค่า)
2. **General** (ทั่วไป) -> **VPN & Device Management** (การจัดการ VPN และอุปกรณ์)
3. กดที่อีเมล **Apple ID ของพี่**
4. กด **Trust** (เชื่อถือ)

🎉 **เสร็จสิ้น!** ตอนนี้พี่ถอดสาย และเอาไปเดินเทสได้เลย 7 วันครับ
ถ้าครบ 7 วันแอปจะเปิดไม่ได้ ต้องมาเสียบสายกด RUN ใหม่ครับ

## 6. การทดสอบแบบถอดสาย (Standalone Mode)
**สำคัญ:** หาก Run แบบปกติ (`flutter run`) แอปจะเป็นโหมด **Debug** ซึ่ง **ต้องเสียบสายกับคอมไว้ตลอดเวลา** ถ้าถอดสายแล้วเปิดใหม่ แอปจะเด้ง (Crash) ทันที

หากต้องการติดตั้งลงเครื่องแล้วถอดสายไปเล่นข้างนอกได้ ให้ทำดังนี้:

1. หยุดการ Run เดิมก่อน (กด `q` หรือ `Ctrl+C`)
2. รันคำสั่งนี้แทน:
   ```bash
   flutter run --release
   ```
3. รอจนติดตั้งเสร็จ (จะนานกว่าปกตินิดนึง เพราะเป็นการ Compile จริง)
4. เมื่อแอปเปิดขึ้นมาแล้ว ให้กด **Stop** (ใน Terminal)
5. **ถอดสาย USB** แล้วลองเปิดแอปเล่นได้เลยครับ!

> **หมายเหตุ:** สำหรับ Free Account แอปจะมีอายุใช้งาน 7 วัน หลังจากนั้นต้องเสียบสาย Run ใหม่ครับ
