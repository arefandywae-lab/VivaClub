# 00: Executive Summary - VivaClub Project

## 1. Project Vision
**VivaClub** is a next-generation mental health ecosystem designed to bridge the gap between anonymous community support and professional medical consultation. By combining an anonymous audio-room platform (Clubhouse-style) with a high-priority telemedicine system, VivaClub provides a safe haven for users to express themselves while ensuring immediate help is available during crisis moments.

## 2. Problem Statement
Traditional mental health apps often suffer from:
1. **High Barriers to Entry:** High cost and long waiting lists for specialists.
2. **Stigma:** Users fear using their real identities when discussing sensitive issues.
3. **Fragmented Care:** Communities for venting are separate from clinical platforms.

## 3. Key Achievements (MVP 1.0)
- **100% Anonymous Community:** Implementing a "Ghost Profile" system to ensure total privacy.
- **Real-time Audio Collaboration:** Scalable audio rooms powered by LiveKit for group therapy and peer support.
- **High-Priority SOS System:** An automated triage system that connects high-risk users (based on PHQ-9 scores) to standby doctors within minutes.
- **Cross-Platform Telemedicine:** A fully functional medical portal for doctors and a seamless patient interface for video consultations.

## 4. Technology Stack
- **Backend:** Python/Django, Django Channels (WebSockets), Redis.
- **Frontend:** Flutter (Mobile), Next.js (Admin Panel).
- **Infrastructure:** Docker, Caddy, LiveKit Server, Firebase Cloud Messaging (FCM).
